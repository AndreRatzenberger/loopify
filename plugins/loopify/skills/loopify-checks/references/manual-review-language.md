# Manual Review Language

Use direct language for subjective gates.

Good:

- "Manual review: confirm dashboard information hierarchy is clear."
- "Visual review: compare 390px and 1280px screenshots for overflow."
- "Source review: verify every factual claim is supported by a cited source."

Bad:

- "Automated test proves it is polished."
- "Looks good."
- "Agent verified manually" without evidence.
