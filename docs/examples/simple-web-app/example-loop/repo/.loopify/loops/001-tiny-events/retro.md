# Loop Retro

## What The Loop Proved

The simple-web-app fixture can be run through the Loopify flow as a real
build/test/visual loop in a disposable project.

## Checks That Mattered

- `npm run build`
- `npx playwright test`
- desktop and 390px screenshots
