# loopify-retro

Extract lessons from completed loops.

## When To Use

- A loop finished.
- Trace data should improve future specs or checks.
- Failures reveal recurring weak spots.

## Workflow

1. Read contract, trace, final diff, and final report.
2. Identify ambiguous spec phrases, useful checks, missing checks, failure
   clusters, authority surprises, and rejected attempts.
3. Write a retro.
4. Recommend template or process updates.

## Output

Loop retro document and optional template improvements.
