# Material Pack Template

Include:

- `app-brief.md`: the normal app target
- `design-direction.md`: visual and interaction constraints
- `seed-data.json`: small fixture data
- `acceptance-checklist.md`: human-readable requirements
- `docs/loop-contract.md`: executable loop contract
- `scripts/quality-gate.sh`: failing first observation
- `runs/trace.md`: empty trace template

The material pack should be public-safe and intentionally small.
