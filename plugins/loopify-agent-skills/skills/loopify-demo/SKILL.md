# loopify-demo

Create demo-ready loop projects.

## When To Use

- The user wants a spectacle demo for "I do not prompt, I loop".
- A seed repo should show a normal app being built by a loop.

## Workflow

1. Choose a visible, normal app target.
2. Create app brief, design direction, seed data, acceptance checklist, quality
   gate, goal prompt, and demo script.
3. Leave the app intentionally incomplete if the demo is the build loop.
4. Verify material checks pass and quality gate fails for the intended
   acceptance reason.

## Output

A loop demo seed repo or material pack.
