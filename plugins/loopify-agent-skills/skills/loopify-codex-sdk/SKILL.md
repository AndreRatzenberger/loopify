# loopify-codex-sdk

Add Codex SDK actuators to loops.

## When To Use

- A loop should call Codex SDK programmatically.
- A project needs a repair, review, evaluator, or trace-summarizer actuator.

## Workflow

1. Read the Loop Contract.
2. Identify the loop step that should use Codex SDK.
3. Verify current official SDK docs before writing concrete API calls.
4. Scaffold script or template with authority boundaries.
5. Ensure outputs are structured enough for the surrounding loop.

## Output

Codex SDK actuator script/template and docs.
